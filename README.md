# Anime Expeditions Macro

Free auto-farm and raid macro for Anime Expeditions - repeats your recorded run on a loop while AFK. Windows 10/11, small installer.

**[⬇ Download for Windows](https://github.com/OWNER/anime-expeditions-macro/releases/latest)** · [Website](https://animeexpeditionsmacro.com)

---

## What it does

Press record, play the raid the way you normally would, press stop - and it loops that sequence until you stop it. A second sequence runs on a longer interval for restarting an expedition or claiming rewards, so an overnight session does not stall on a menu.

## Features

- Records a full run from your own keyboard and mouse
- Loops the recorded sequence until you stop it
- Second sequence for restarting expeditions and claiming rewards
- Delays in milliseconds with random jitter
- Global hotkey to start and stop without leaving the game
- Named profiles, one per raid, swapped in a click
- Run counter showing completed loops
- Small installer, no extra components, free and open source (MIT)

## Install

1. Download the latest release: **[Anime Expeditions Macro](https://github.com/OWNER/anime-expeditions-macro/releases/latest)**
2. Run the installer. No admin rights, no extra components.
3. Start it from the Start menu.

Windows 10 and Windows 11, 64-bit. Nothing else is required.
